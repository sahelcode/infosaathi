# InfoSaathi

বাংলাদেশের ডাক্তার, হাসপাতাল ও অন্যান্য তথ্যের ডিরেক্টরি। Astro দিয়ে বানানো স্ট্যাটিক সাইট। Cloudflare Pages-এ চলে।

## নতুন পোস্ট যেভাবে করবেন

প্রতিটা ডাক্তার বা হাসপাতাল = একটা ছোট `.yaml` ফাইল। ডিজাইন, টাইটেল, ডেসক্রিপশন, Google-এর Schema, FAQ সব টেমপ্লেট নিজে তৈরি করে।

1. `src/content/doctors/_template.yaml` কপি করুন। নতুন নাম দিন, যেমন `dr-rahim-uddin.yaml`।
   ফাইলের নামটাই পেজের লিংক হবে: `infosaathi.com/doctor/sylhet/dr-rahim-uddin/`। পরে নাম বদলাবেন না।
2. তথ্য বদলান। প্রথমে `draft: true` রাখুন।
3. ফোন করে নম্বর, ঠিকানা, সময় যাচাই করুন। `verified:`-এ আজকের তারিখ দিন, তারপর `draft: true` লাইনটা মুছুন।
4. GitHub-এ ফাইলটা আপলোড করুন (ফোন থেকেও হয়: রিপোজিটরিতে Add file → Upload files)।
   Cloudflare ১–২ মিনিটে সাইট আপডেট করে দেবে।

হাসপাতালের জন্য একই নিয়ম: `src/content/hospitals/_template.yaml`।
হাসপাতালের পেজে ডাক্তারের তালিকা নিজে থেকে আসে, যে ডাক্তারের চেম্বারে সেই হাসপাতালের ফাইলের নাম লেখা আছে।

ছবি: `src/content/doctors/images/` ফোল্ডারে রাখুন, ফাইলে `photo: ./images/নাম.webp` লিখুন। সাইট নিজেই ছবি ছোট করে নেয়।

দর্শনীয় স্থান: `src/content/places/jaflong.yaml` কপি করে নমুনা হিসেবে ব্যবহার করুন। লিংক হবে `infosaathi.com/place/sylhet/jaflong/`।
নিজের তোলা ২–৩টি ছবি `src/content/places/images/`-এ রেখে লিখুন:
```yaml
photos:
  - { src: ./images/jaflong-1.jpg, caption: "পিয়াইন নদী ও পাথরের চর", sub: "জিরো পয়েন্ট", label: "জিরো পয়েন্ট" }
```
ছবি না থাকলে `kind` অনুযায়ী আঁকা ছবি দেখায়। নিজে ঘুরে এসে তথ্য মিলালে `verified_by: visited` দিন।

## পুরনো Blogger পোস্ট

`src/content/doctors/`-এর বেশিরভাগ ফাইল পুরনো পোস্ট থেকে স্বয়ংক্রিয়ভাবে তৈরি খসড়া (`draft: true`)।
প্রতিটা ফাইলের ওপরে # দিয়ে লেখা আছে কী যাচাই করতে হবে। যাচাই শেষে `draft: true` মুছলে পেজ লাইভ হয়,
আর `old_urls`-এ লেখা পুরনো লিংক নিজে থেকে নতুন পেজে চলে যায় (301 redirect, Google র‍্যাঙ্কিং সাথে আসে)।
খসড়া অবস্থায় একটা চেম্বারের দিন/সময়/নম্বর ফাঁকা রাখা যায়, কিন্তু প্রকাশের আগে সব দিতে হবে, না দিলে বিল্ড থামবে।

## ভুল হলে কী হয়

কোনো ফাইলে ভুল থাকলে (ফোন নম্বরে সংখ্যা কম, ভুল দিনের নাম, ভুল হাসপাতালের নাম) সাইট আপডেট **হবে না**।
Cloudflare-এর build log-এ বাংলায় লেখা থাকবে কোন ফাইলের কোন লাইনে কী ভুল। ঠিক করে আবার আপলোড করলেই হবে।
লাইভ সাইট আগের মতোই চলতে থাকে, তাই ভুল তথ্য কখনো পাবলিশ হয় না।

## নিয়মগুলো

- ফোন নম্বর ও সময় উদ্ধৃতিচিহ্নের ভেতরে লিখুন: `number: "09610009640"`, `start: "17:00"`
- দিন: `শনি রবি সোম মঙ্গল বুধ বৃহস্পতি শুক্র`, অথবা `প্রতিদিন`
- শহর ও বিশেষজ্ঞতা `src/lib/taxonomy.ts`-এর তালিকা থেকে। নতুন লাগলে সেখানে একটা লাইন যোগ করুন।
- `_` দিয়ে শুরু হওয়া ফাইল (`_template.yaml`) কখনো পাবলিশ হয় না।

## কম্পিউটারে চালানো (ঐচ্ছিক)

```
npm install
npm run dev      # http://localhost:4321 , draft পেজও দেখায় (কমলা দাগসহ)
npm run build    # আসল সাইট dist/ ফোল্ডারে, draft ছাড়া
```

## Cloudflare Pages সেটআপ (একবার)

Build command: `npm run build` · Output directory: `dist` · Environment: `NODE_VERSION=22`

## ফোল্ডার

```
src/content/doctors/     ডাক্তারের ফাইল
src/content/hospitals/   হাসপাতালের ফাইল
src/content.config.ts    কোন ঘরে কী লেখা যাবে, তার নিয়ম
src/lib/taxonomy.ts      শহর, বিশেষজ্ঞতা, সুবিধার তালিকা
src/lib/site.ts          সাইটের সেটিং (AdSense আইডি এখানে)
src/pages/               পেজের টেমপ্লেট
public/index.html        হোমপেজ (আপাতত আগের ডিজাইন যেমন আছে)
public/_redirects        পুরনো Blogger লিংক → নতুন পেজ
```

## হোটেল
`src/content/hotels/grand-sylhet-hotel-resort.yaml` কপি করে নমুনা বানান। লিংক হবে `infosaathi.com/hotel/sylhet/<ফাইলের নাম>/`। সুবিধা শুধু `src/lib/taxonomy.ts`-এর `HOTEL_FACILITIES` তালিকার নাম দিয়ে লিখবেন। রেটিং নেই, কারণ আসল রিভিউ জমা না হওয়া পর্যন্ত নকল রেটিং দেখানো হয় না। হোটেল রুমের ভাড়া ডলারে দিলে `rooms: []` রেখে `price_note`-এ ফোনে জেনে নিতে লিখুন।

## স্কলারশিপ, চাকরি, AI টুলস, সরকারি সেবা
ফোল্ডার: `src/content/scholarships/`, `jobs/`, `ai-tools/`, `services/`। প্রতিটাতে `chevening-bangladesh.yaml`, `bpsc-51-bcs.yaml`, `claude.yaml` ধরনের ফাইল নমুনা। নিয়ম:
- স্কলারশিপ ও চাকরিতে `close` (শেষ তারিখ) লাগবেই। তারিখ পার হলে পেজে নিজে থেকে "আবেদন শেষ" দেখায়, আর হোমপেজে শেষের দিকে চলে যায়। তবে হোমপেজ নতুন করে সাজাতে সাইট একবার আপডেট (পুশ) করতে হয়।
- AI টুলের দাম বদলায়। `verified:`-এ তারিখ দিন, মাসে একবার অফিসিয়াল দামের পেজ মিলিয়ে নিন।
- সরকারি সেবার ফি অফিসিয়াল পোর্টাল দেখে লিখুন। `services/`-এ ফাইল দিলে `/service/<নাম>/` পেজ নিজে তৈরি হবে।

## সব সেকশনে ছবি যোগ করার নিয়ম
ধাপগুলো সবখানে এক: (১) ছবি সেই সেকশনের `images/` ফোল্ডারে রাখুন, (২) ফাইলে ছবির পথ লিখুন, (৩) পুশ করুন। সাইট নিজেই ছবি ছোট ও webp করে নেয়, তাই আসল ছবি বড় দিলেও চলে।

| সেকশন | ফোল্ডার | ফাইলে কী লিখবেন |
|---|---|---|
| ডাক্তার | `doctors/images/` | `photo: ./images/নাম.webp` (চেম্বারের ব্যানার: `banner:`) |
| হাসপাতাল | `hospitals/images/` | `photo: ./images/নাম.webp` |
| বিশ্ববিদ্যালয় | `universities/images/` | `logo:` ও `photo:` |
| কলেজ, স্কুল | `institutions/images/` | `logo:` ও `photo:` |
| দর্শনীয় স্থান | `places/images/` | `photos:` (সর্বোচ্চ ৫টি, প্রতিটিতে `caption` লাগবে); প্রতিটি `spots`-এও আলাদা `photo:` দেওয়া যায় |
| হোটেল | `hotels/images/` | `photos:` (সর্বোচ্চ ৫টি) ও `logo:` |
| স্কলারশিপ, চাকরি, AI টুল, সরকারি সেবা | (ছবি নেই) | আঁকা ছবি দেখায়। প্রতিষ্ঠানের লোগো দিতে চাইলে আগে বলুন, স্কিমায় যোগ করতে হবে |

ছবির নিয়ম:
- শুধু নিজের তোলা ছবি, বা যে ছবির অনুমতি/লাইসেন্স আছে। গুগল থেকে তোলা ছবি নয়।
- ডাক্তারের ছবি ও ব্যক্তিগত তথ্য তাঁর অনুমতি নিয়ে দিন।
- ফাইলের নাম ইংরেজিতে, ছোট হাতের, `-` দিয়ে (যেমন `jaflong-1.webp`)। নাম বাংলা বা ফাঁকসহ দিলে পথ ভাঙতে পারে।
- আকার: প্রস্থ ১৬০০px-এর বেশি লাগবে না। এক ছবি ৫০০ KB-এর নিচে রাখলে সাইট দ্রুত থাকে।
- ছবি না থাকলে পেজ ভাঙে না। জায়গাটা শূন্য থাকে বা আঁকা ছবি দেখায়।
- ভুল পথ দিলে `npm run build` থামবে ও কোন ফাইলে ভুল সেটা বলবে। পুশের আগে একবার build চালিয়ে নিন।
